# Blocks – multiplayer 3D block game

Run locally: `npm install && npm start`, then open http://localhost:3000 (open two tabs to test multiplayer).

## Deploy on Render
1. Push this folder to a GitHub repo.
2. On render.com: New → Web Service → connect the repo.
3. Build command: `npm install` · Start command: `npm start`
4. Deploy, then share the `.onrender.com` URL.

Note: the world lives in server memory, so it resets when the server restarts or sleeps (free tier).
